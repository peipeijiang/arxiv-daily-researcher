# 并行生成式推荐的自适应语义容量分配

> **英文原标题**：Adaptive Semantic Capacity Allocation for Parallel Generative Recommendation

<summary><strong>中文摘要</strong></summary>

自回归语义ID推荐器受限于昂贵的集束搜索解码，这限制了物品标识符的实际长度。并行生成方法通过同时预测所有语义ID标记来缓解这一瓶颈，从而支持更长的ID。然而，现有的语义ID方法仍依赖于人工预定义且同质的ID结构，其中语义槽的数量及每个槽的码本大小均被视为固定超参数。这忽略了不同语义子空间在容量需求上的异质性，并可能将预测能力分配给效用有限的槽位。我们表明，均匀扩展语义槽仅能带来有限的增益，这揭示了同质语义ID中存在冗余容量。我们提出InforID，一种用于并行生成式推荐的轻量级自适应语义目标构建框架。InforID在候选语义槽之间分配固定的容量预算，从而联合确定有效的ID长度和槽特定的码本大小。实验表明，在可比较的容量预算下，InforID提升了推荐准确性，同时保持了一步并行预测的能力。

<summary><strong>英文摘要</strong></summary>

Autoregressive semantic ID recommenders are constrained by expensive beam-search decoding, which limits the practical length of item identifiers. Parallel generation methods alleviate this bottleneck by predicting all semantic ID tokens simultaneously, enabling longer IDs. However, existing semantic ID methods still rely on manually predefined and homogeneous ID structures, where both the number of semantic slots and the codebook size of each slot are treated as fixed hyperparameters. This ignores the heterogeneous capacity demands of different semantic subspaces and may allocate prediction capacity to slots with limited utility. We show that uniformly expanding semantic slots can provide limited gains, indicating redundant capacity in homogeneous semantic IDs. We propose InforID, a lightweight adaptive semantic target construction framework for parallel generative recommendation. InforID allocates a fixed capacity budget across candidate semantic slots, thereby jointly determining the effective ID length and slot-specific codebook sizes. Experiments demonstrate improved recommendation accuracy under comparable capacity budgets while preserving one-step parallel prediction.

## 深度解读

> 分析依据：**全文深读**

### 核心结论

本文针对并行生成式推荐中语义ID结构手动预定义且同质化的问题，提出InforID框架。该框架将语义ID构建视为目标空间容量分配问题，通过贪心算法在候选语义槽间分配固定容量预算，自适应确定有效ID长度和每个槽的码本大小，移除零比特槽，保留异构语义ID。实验表明，InforID在四个数据集上优于现有方法，且保持一步并行预测效率。

### 主要创新

- 识别出语义ID推荐中手动预定义同质ID结构这一被忽视的局限。
- 提出InforID，一种轻量级自适应语义目标构建框架，用于并行生成式推荐。
- 通过自适应容量分配，联合确定有效ID长度和槽特定码本大小。
- 在保持并行预测优势的同时，提升推荐准确率。

### 研究方法

首先，利用OPQ将项目表示投影并划分为M个等大小子空间作为候选语义槽。然后，通过贪心算法分配总比特预算B，每次迭代选择边际重建损失减少最大的槽分配一个比特，直至预算耗尽。零比特槽被移除，保留槽的码本大小由分配的比特数决定。最后，使用Transformer解码器作为骨干，采用并行预测头预测各槽的语义ID，以多令牌预测损失训练，推理时以对数概率和作为评分。

### 关键结果

在Sports、Beauty、Toys和CDs四个数据集上，InforID在Recall@5、NDCG@5、Recall@10、NDCG@10指标上均优于或持平于基线方法，如RPG。在容量分配分析中，InforID相比PQ和OPQ取得更低的重建损失和更高的NDCG@10。预算敏感性分析显示性能随预算增加而提升但逐渐饱和。

### 技术栈

- OPQ（优化乘积量化）
- k-means聚类
- Transformer解码器
- 并行预测头
- 贪心算法
- 多令牌预测损失

### 方法优势

- 方法轻量且即插即用，不改变推理范式。
- 自适应容量分配能更好地匹配语义子空间的异构容量需求。
- 实验验证了方法的有效性，并进行了消融和敏感性分析。

### 主要局限

- 容量分配基于重建损失代理，可能未完全反映下游检索性能。
- 贪心分配可能不是全局最优。
- 实验仅在四个数据集上进行，泛化性有待验证。

### 与当前研究方向的关联

该论文属于序列推荐和生成式推荐领域，聚焦于语义ID构建，与关键词“序列推荐”、“生成式推荐”高度相关。
