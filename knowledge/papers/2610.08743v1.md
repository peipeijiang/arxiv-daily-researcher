# 基于共形动作集的强化学习：在序列推荐中的应用

> **英文原标题**：Reinforcement Learning with Conformal Action Sets: An Application to Sequential Recommendation

[查看原文](http://arxiv.org/abs/2610.08743v1)

## 一句话结论

> 针对序列推荐中固定候选集大小的问题，提出基于共形预测的动态剪枝强化学习方法RLCP，在KuaiRand-Pure和MovieLens 1M上实验表明，在19种配置中至少一种RLCP变体达到最高目录多样性（1.11倍至5.21倍于最强基线），同时保持有竞争力的会话深度且保留集更小。

<summary><strong>中文摘要</strong></summary>

序贯推荐器通常使用固定的候选集大小，即便在一个会话中有用替代项的数量会发生变化。我们提出校准剪枝强化学习（Reinforcement Learning with Calibrated Pruning, RLCP），该方法利用评论家分数和在线阈值自适应地调整保留的动作集。该阈值根据二元反馈进行更新，该反馈指示集合中是否包含代理目标中的某个动作。我们证明了沿自适应轨迹观测到的代理漏检率的确定性上界。为了量化剪枝对奖励的影响，我们推导了价值损失分解为过滤损失和选择损失的精确分解。在显式的代理和评论家近似条件下，该分解给出了一个有限的会话奖励上界，该上界还考虑了不完美选择和集合截断，且不要求学习参数收敛。在KuaiRand-Pure和MovieLens 1M上的实验比较了两种RLCP实现与四种强化学习基线。在19种配置中的每一种中，至少有一种RLCP变体实现了最高的目录多样性，达到最强基线的$1.11\times$至$5.21\times$，同时具有竞争力的会话深度且保留集合不大。

<details>
<summary><strong>英文摘要</strong></summary>

Sequential recommenders typically use a fixed slate size even though the number of useful alternatives changes within a session. We propose Reinforcement Learning with Calibrated Pruning (RLCP), which adapts the retained action set using critic scores and an online threshold. The threshold is updated from binary feedback indicating whether the set contains an action in a proxy target. We prove a deterministic bound on the observed proxy miss rate along adaptive trajectories. To quantify the effect of pruning on reward, we derive an exact decomposition of value loss into filtering and selection losses. Under explicit proxy and critic approximation conditions, this decomposition yields a finite session reward bound that also accounts for imperfect selection and set truncation, without requiring the learning parameters to converge. Experiments on KuaiRand-Pure and MovieLens 1M compare two RLCP implementations with four RL baselines. In each of the 19 configurations, at least one RLCP variant achieves the highest catalog diversity, reaching $1.11\times$ to $5.21\times$ that of the strongest baseline, with competitive session depth and no larger retained sets.

## 深度解读

> 分析依据：**全文深读**

### 核心结论

序列推荐通常使用固定候选集大小，但会话中有用替代项的数量会变化。本文提出基于校准剪枝的强化学习（RLCP），利用评论家分数和在线阈值自适应保留动作集。阈值根据二元反馈更新，该反馈指示集合是否包含代理目标中的动作。作者证明了沿自适应轨迹的确定性代理遗漏率界，并推导了价值损失分解为过滤损失和选择损失。在显式代理和评论家近似条件下，该分解给出有限会话奖励界，且不要求学习参数收敛。在KuaiRand-Pure和MovieLens 1M上的实验比较了两种RLCP实现与四种RL基线，在19种配置中至少一种RLCP变体达到最高目录多样性，为最强基线的1.11倍至5.21倍，同时会话深度具有竞争力且保留集不大于基线。

### 主要创新

- 提出RLCP框架，通过学习分数和在线保留校准构建动作集，采用双层公式在保留动作诱导的策略下评估集合大小和保留率，考虑过滤对后续状态访问的影响。
- 建立确定性代理遗漏界和精确价值分解，共同给出折扣价值和有限会话奖励的条件界，量化代理误差、评论家误差、选择误差和集合截断的影响。
- 在KuaiRand-Pure和MovieLens 1M上评估两种RLCP实现与四种RL基线，至少一种变体在每种配置中达到最高目录多样性，同时会话深度具有竞争力且平均保留集不大于对应基线。
- 共形组件基于现有在线校准方法，重点研究校准保留如何与动作过滤和序列价值交互。

### 研究方法

论文考虑有限折扣MDP，定义代理目标动作集为最优值差距在ε内的动作。RLCP使用评论家分数g_θ(s,a)和阈值τ构建原始集C_θ,τ(s)，当原始集为空时使用最小分数回退。阈值通过在线校准更新τ_{t+1}=τ_t+η_t(e_t-α)，其中e_t为代理遗漏指示。采用双层优化问题：内层在保留动作集上最大化价值，外层在诱导占用下最小化期望集大小并满足保留约束。理论分析包括路径遗漏率跟踪定理、过滤-选择价值恒等式和有限会话代理到价值保证。实验在KuaiSim模拟器上进行，使用KuaiRand-Pure和MovieLens 1M数据集，比较A2C、DDPG、TD3、HAC基线，评估会话深度、目录多样性、列表内多样性等指标。

### 关键结果

在19种实验配置中，至少一种RLCP变体达到最高目录多样性，为最强基线的1.11倍至5.21倍，同时会话深度具有竞争力且保留集不大于基线。；在KuaiRand-Pure上，RLCP-Single在全部十种配置中达到最高目录多样性，为最强基线的1.48倍至4.56倍；其平均保留集在九种配置中小于M，最大减少25.5%，在剩余配置中等于M；在六种配置中达到或并列最高会话深度，在其他配置中与最佳方法相差不超过0.4次交互。；在ML-1M上，完整RLCP在五种配置中领先目录多样性，在八种配置中超过最强基线，在七种配置中达到或并列最高会话深度，并始终保持ILD为1.00，在四种配置中将平均集大小降至M以下。RLCP-Single在剩余四种配置中领先目录多样性，每种配置中较优变体达到最强基线目录多样性的1.11倍至5.21倍。；在较长耐心设置下，目录多样性优势范围为3.17倍至5.21倍，尽管若干方法达到深度上限48。

### 方法优势

- 理论贡献扎实：提供了确定性代理遗漏率界、精确价值分解和有限会话奖励界，不要求学习参数收敛。
- 方法创新明确：将共形校准与动作集剪枝结合，自适应调整保留集大小，而非固定候选集大小。
- 实验全面：在19种配置中比较两种RLCP变体与四种RL基线，覆盖两个数据集和多种奖励与耐心设置。
- 结果显著：在目录多样性上一致优于基线，同时保持竞争性会话深度和更小或相等的保留集。
- 分析细致：区分过滤损失和选择损失，明确代理保留与最优保留的差异，并讨论模型假设和适用条件。

### 主要局限

- 代理目标基于模拟器的即时响应模型，对长期最优Q*存在偏差，可能影响理论保证的实际适用性。
- 理论保证依赖于代理保真度和评论家近似等假设条件，这些条件在实际部署中可能难以验证或满足。
- 实验仅在模拟器中进行，未在真实在线推荐系统中验证，实际效果可能受模拟器保真度限制。
- 方法需要合适的验证器或反事实响应模型来提供代理反馈，部署成本较高。
