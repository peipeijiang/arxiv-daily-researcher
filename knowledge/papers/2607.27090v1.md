# InferScale: GPU-Native KV Injection for Personalized LLM Serving

<summary><strong>中文摘要</strong></summary>

大型语言模型正越来越多地部署带有持久化个性化上下文的场景，例如累积的记忆档案或长对话历史，这些内容会在用户的多次请求间共享。生产级记忆系统（如Mem0、MemGPT和Zep）会检索这部分记忆的相关子集并将其注入提示词中，迫使服务引擎重复预填充相同的内容。随着检索预算的增长，即使底层记忆在请求间被复用，首令牌延迟（TTFT）仍会增加。

我们提出InferScale，一种GPU原生的大语言模型记忆系统，它用可复用的KV状态替代重复的提示词预填充。InferScale预先计算每条记忆事实的KV表示，将其与语义嵌入一同存储在GPU上，在服务时检索相关事实，并直接将它们的KV注入vLLM的分页缓存中。为了支持在旋转位置编码（RoPE）下动态组合的记忆，我们引入了分块RoPE（Chunked RoPE），该方法在旋转前存储键，并在注入时应用其服务时的位置。然而，独立编码记忆事实会丢失联合预填充时存在的跨事实上下文。我们通过上下文窗口编码（Context-Window Encoding）来缓解这一问题，该方法将每条记忆事实与前面一小段对话上下文一起编码，同时仅缓存目标事实的KV。

InferScale通过vLLM的KV连接器接口实现，既不需要修改引擎，也不需要微调模型。在LoCoMo数据集上，针对三个开放权重模型，InferScale在检索预算增加时几乎保持TTFT恒定：在k=50时，它将TTFT降低了72-79%（3.6-4.8倍），在无需服务时重新计算的情况下，准确率达到60.3%（而Mem0为63.3%），并在并发负载下提供了3.7-4.5倍的吞吐量。因此，可复用的KV状态将记忆条件下的服务延迟与检索上下文大小解耦，同时保持了应用质量。

<summary><strong>英文摘要</strong></summary>

Large language models are increasingly deployed with persistent personalized context, such as accumulated memory profiles or long conversation histories, that is shared across a user's many requests. Production memory systems (e.g., Mem0, MemGPT, and Zep) retrieve a relevant subset of this memory and inject it into the prompt, forcing the serving engine to repeatedly prefill the same content. As the retrieval budget grows, time-to-first-token (TTFT) increases even though the underlying memory is reused across requests.
  We present InferScale, a GPU-native LLM memory system that replaces repeated prompt prefilling with reusable KV state. InferScale precomputes each memory fact's KV representation, stores it alongside a semantic embedding on the GPU, retrieves relevant facts at serving time, and injects their KV directly into vLLM's paged cache. To support dynamically assembled memories under rotary position embeddings, we introduce Chunked RoPE, which stores keys before rotation and applies their serving-time positions during injection. However, encoding memory facts independently omits the cross-fact context available during joint prefilling. We mitigate this with Context-Window Encoding, which encodes each memory fact together with a small window of preceding conversation context while caching only the target fact's KV.
  InferScale is implemented through vLLM's KV-connector interface, requiring neither engine modifications nor model fine-tuning. Across three open-weight models on LoCoMo, InferScale keeps TTFT nearly constant as the retrieval budget increases: at k=50 it reduces TTFT by 72-79% (3.6-4.8x), achieves 60.3% accuracy versus 63.3% for Mem0 without serving-time recomputation, and delivers 3.7-4.5x the throughput under concurrent load. Reusable KV state thus decouples memory-conditioned serving latency from retrieved-context size while preserving application quality.
