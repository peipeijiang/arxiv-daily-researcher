# 审计返回条件作为控制旋钮：决策Transformer推荐的离线诊断

离线返回目标（RTG）扫描可以检验一个以返回为条件的推荐器是否可控，但这种干预很少被审计。重写每一个历史RTG标记会创造一个日益合成的上下文，而仅重写当前标记则更具局部性。我们在固定窗口的离线设置中检验了这一区别。在MovieLens 25M和MyAnimeList 2020（MAL）数据集上，我们使用RTG局部性阶梯、无RTG对照、记录匹配与得分奖励检查，以及轨迹内洗牌RTG消融，评估了一个决策Transformer。在MovieLens上，覆盖完整上下文的$K=20$干预仅应用于真实上下文位置时，将犯罪类预测的份额从验证集的第5百分位到第95百分位移动了$+23.61 \pm 2.96$个百分点，而仅改变当前槽位则使其移动了$+1.77 \pm 1.17$个百分点。洗牌RTG模型在很大程度上消除了这种响应（在$K=20$时为$+2.08 \pm 1.20$个百分点）。在MAL上，相同的协议并未产生戏剧类响应：$K=20$使戏剧类变化了$-0.03 \pm 0.07$个百分点，$K=1$使其变化了$-0.01 \pm 0.01$个百分点。在真实RTG、无RTG和洗牌RTG条件下，类型预测准确率在数值上接近，且在$K=1$时，记录匹配率和匹配评分变化很小。由于数据集和焦点类型的选择具有探索性，这些数值仅具有描述性；跨局部性、洗牌RTG以及MAL上的零结果所呈现的交叉诊断模式并未确立奖励控制。我们提出了四项检查：干预局部性、无RTG基线、奖励检查以及RTG内容消融。

<summary><strong>英文摘要</strong></summary>

Offline return-to-go (RTG) sweeps can test whether a recommender conditioned on return is controllable, but the intervention is rarely audited. Rewriting every historical RTG token creates an increasingly synthetic context, while rewriting only the current token is more local. We test this distinction in an offline setting with a fixed window. On MovieLens 25M and MyAnimeList 2020 (MAL), we evaluate a Decision Transformer using an RTG locality ladder, a control without RTG, a logged match and score reward check, and a within-trajectory shuffled RTG ablation. On MovieLens, a $K=20$ intervention that covers the full context, applied only to real context positions, shifts the share of Crime predictions by $+23.61 \pm 2.96$ percentage points from the validation 5th to 95th percentile, whereas changing only the current slot shifts it by $+1.77 \pm 1.17$ points. The shuffled RTG model largely removes this response ($+2.08 \pm 1.20$ points at $K=20$). On MAL, the same protocol does not produce a Drama response: $K=20$ changes Drama by $-0.03 \pm 0.07$ points, and $K=1$ by $-0.01 \pm 0.01$. Genre prediction accuracy is numerically close across real RTG, no RTG, and shuffled RTG, and at $K=1$ logged match rates and matched ratings change little. Because dataset and focus-genre selection were exploratory, these magnitudes are descriptive; the cross-diagnostic pattern across locality, shuffled RTG, and the null result on MAL does not establish reward control. We propose four checks: intervention locality, a no-RTG baseline, a reward check, and RTG-content ablation.

## 深度解读

> 分析依据：**全文深读**

### 核心结论

本文针对决策Transformer（DT）在推荐系统中通过返回条件（RTG）实现可控性的离线评估方法进行审计。作者提出了一种RTG局部性阶梯（locality ladder）诊断方法，通过改变历史RTG重写的数量（K=1到20）来区分局部控制与合成上下文效应。在MovieLens 25M和MyAnimeList 2020数据集上，实验发现MovieLens上全上下文重写（K=20）能显著改变犯罪类别的预测份额（+23.61个百分点），而仅改变当前槽位（K=1）效果微弱（+1.77个百分点），且打乱RTG后效应消失。MAL上则无显著效应。此外，RTG对预测准确率的提升很小，且匹配奖励检查未显示改善。作者提出四项诊断检查：干预局部性、无RTG基线、奖励检查、RTG内容消融，并强调离线RTG扫描应作为敏感性分析而非控制性证据。

### 主要创新

- 提出RTG局部性阶梯（locality ladder）诊断方法，通过改变重写历史RTG的位置数量来区分局部控制与合成上下文效应。
- 引入打乱RTG（shuffled RTG）作为控制条件，以分离RTG通道存在与内容对齐的影响。
- 结合无RTG基线、匹配奖励检查、RTG内容消融等多项诊断，形成系统的离线审计协议。
- 在MovieLens和MAL两个数据集上进行了跨域验证，揭示了RTG效应的数据集依赖性。

### 研究方法

使用决策Transformer（DT）进行序列推荐，状态为用户历史交互的摘要（包括类型直方图、平均评分等），动作为物品主类型，奖励为归一化评分。RTG定义为未来20个交互的奖励和。训练时使用真实RTG，评估时通过覆盖不同数量的RTG位置（K=1到20）进行干预。同时训练无RTG、打乱RTG和SASRec基线。通过比较不同干预下的类型份额变化、匹配率和匹配评分，以及预测准确率，来评估RTG的控制效果。

### 关键结果

MovieLens上，K=20时犯罪类型份额变化+23.61±2.96个百分点，K=1时仅+1.77±1.17个百分点；打乱RTG后K=20时变化降至+2.08±1.20个百分点。MAL上，K=20时戏剧类型变化-0.03±0.07个百分点，K=1时-0.01±0.01个百分点。RTG对预测准确率的提升很小（MovieLens HR@1提升0.14个百分点，MAL几乎无提升）。匹配奖励检查显示K=1时匹配率和评分变化很小。

### 方法优势

- 提出了一种新颖的离线审计方法，能够区分局部控制与合成上下文效应。
- 实验设计严谨，包含多种控制条件（无RTG、打乱RTG）和跨数据集验证。
- 结果揭示了RTG效应的数据集依赖性，提醒研究者谨慎解读离线RTG扫描结果。
- 提供了可复现的细节（种子、训练步数、数据划分等）。

### 主要局限

- 仅使用类型作为动作，简化了真实推荐场景。
- 匹配奖励检查仅评估日志中出现的动作，存在选择偏差。
- 数据集选择是探索性的，未预先注册，可能引入选择偏差。
- 未进行在线实验或策略评估，结论仅限于离线诊断。
