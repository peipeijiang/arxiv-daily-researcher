# FastEEP: Fast Intra-Instance Elastic Scaling for Expert-Parallel MoE Serving

[查看原文](http://arxiv.org/abs/2610.18451v1)

## 一句话结论

> 针对 MoE 模型专家并行服务中实例级伸缩开销大的问题，提出基于部分复用原则的实例内快速弹性伸缩系统 FastEEP，通过复用运行时状态、GPU 内存和通信资源，实现比 vLLM 基线快 4.5–11.7 倍的伸缩速度。

<summary><strong>中文摘要</strong></summary>

大规模专家并行（Expert Parallelism, EP）已成为生产环境中混合专家（Mixture-of-Experts, MoE）模型的标准部署配置。与此同时，大语言模型（LLM）工作负载的高度动态特性要求服务提供商持续调整服务容量以匹配波动的需求。MoE服务的扩缩容无法通过简单地增加或移除服务实例来高效实现；相反，它通常需要在现有实例内调整EP组的大小，我们将其称为实例内扩缩容。现有推理引擎主要依赖实例级扩缩容，即销毁并重建整个服务实例，从而产生大量的扩缩容开销。

我们提出FastEEP（Fast Elastic Expert Parallel），一种基于部分复用（Partial Reuse）原则的MoE服务快速实例内扩缩容系统。FastEEP通过将可复用的执行结构与当前EP配置所激活的资源分离，在worker执行、GPU内存和通信层面复用现有的运行时状态。这种分离使得协调的资源回收与重配置成为可能，同时保留了重建代价高昂的状态，从而无需完全拆除和重建实例即可实现快速EP扩缩容。我们的评估表明，FastEEP在不同模型上相比现有基于vLLM的方法实现了4.5倍至11.7倍的扩缩容加速，从而实现了MoE服务的高效细粒度扩缩容。

<summary><strong>英文摘要</strong></summary>

Large-scale expert parallelism (EP) has become the standard deployment configuration for Mixture-of-Experts (MoE) models in production. Meanwhile, the highly dynamic nature of LLM workloads requires providers to continuously adjust serving capacity to match fluctuating demand. Scaling MoE serving cannot be efficiently achieved by simply adding or removing serving instances; instead, it often requires resizing the EP group within an existing instance, which we refer to as intra-instance scaling.Existing inference engines primarily rely on instance-level scaling, which destroys and reconstructs entire serving instances, incurring substantial scaling overhead.
  We present FastEEP (Fast Elastic Expert Parallel), a fast intra-instance scaling system for MoE serving based on the principle of Partial Reuse. FastEEP reuses existing runtime state across worker execution, GPU memory, and communication by separating reusable execution structures from the resources activated by the current EP configuration. This separation enables coordinated resource reclamation and reconfiguration while preserving costly-to-reconstruct state, allowing fast EP scaling without full instance teardown and reconstruction. Our evaluation shows that FastEEP achieves 4.5x--11.7x faster scaling than the existing vLLM-based approach across different models, enabling efficient, fine-grained scaling of MoE serving.
